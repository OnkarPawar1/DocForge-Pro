# DocForge Pro

> **All-in-one document toolkit** — 100+ features, entirely in your browser.

🔒 Private · ⚡ Client-side · 💰 Free · 📦 No Upload Required

## Features

### Viewers
- **PDF Viewer** — Zoom, search, thumbnails, rotation, reading modes, presentation mode
- **EPUB Reader** — Customizable fonts, themes, TOC navigation, bookmarks

### PDF Manipulation
- **PDF Splitter** — Split by pages, ranges, or fixed chunks with visual selection
- **PDF Merger** — Combine multiple PDFs with drag-and-drop reordering
- **PDF Editor** — Watermarks, rotation, page numbers, headers/footers, annotations

### Extraction
- **Image Extractor** — Extract images from PDF pages with gallery preview
- **Video to Frames** — Capture frames at custom intervals, duplicate detection

### Conversion (12 formats)
- Images, HTML, DOCX, Text, CSV, JSON, SVG, Markdown, EPUB → PDF
- PDF → Images, PDF → Text
- Screenshot → PDF

### PDF Creator (8 templates)
- Invoice, Certificate, Resume, Business Letter, Report, Business Card, Clipboard, Blank

### Analysis & Security
- **PDF Analysis** — File info, text stats, word frequency, document comparison
- **PDF Security** — Metadata editor, sanitization, visual redaction

### Workspace
- **Notepad Pro** — Rich text editor with 25+ features, auto-save, PDF/TXT/HTML export
- **Prompt Gallery** — Color-coded sticky notes, search, pin, import/export

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no build step required)
- PDF.js for rendering
- pdf-lib for manipulation
- jsPDF for generation
- epub.js for e-books
- All processing is 100% client-side

## Deploy

This is a static site — deploy to GitHub Pages, Netlify, Vercel, or any static host.

```bash
# Local development
python3 -m http.server 8080
```
